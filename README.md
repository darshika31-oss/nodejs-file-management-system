# Node.js File Management System

A web-based File Management System built using Node.js, HTML, CSS, and JavaScript.

## Features

- Create new files
- View created files
- Read file contents
- Delete files
- Simple and user-friendly interface

## Technologies Used

- Node.js
- HTML
- CSS
- JavaScript

## Project Structure

```text
Project/

│   ├── index.html
│   └── style.css
├── server.js
├── package.json
├── package-lock.json
└── README.md
```

## Installation and Setup

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the server:

   ```bash
   npm start
   ```

5. Open the local URL shown in the terminal.

## Purpose

This project demonstrates file handling and basic backend development using Node.js.
